02 · Frozen contract

One actuator per action dimension

RL environment

  • Box(-1,1,(3,),float32).
  • Order: thigh, leg, foot.
  • No-op: [0,0,0].
  • 125 Hz environment and observation clock.
  • Zero action latency.

OpenVLA handoff

  • Canonical rows store the environment-confirmed applied action.
  • Bridge carrier: [a0,a1,a2,0,0,0,0].
  • active_action_dim=3, action_dim=7.
  • The four trailing dimensions are padding.
