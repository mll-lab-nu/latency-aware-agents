02 · Frozen contract

Humanoid-v4 semantics preserved without a bridge carrier

Version-matched API facts

  • Repository runtime: Gymnasium 0.29.1; selected environment: Humanoid-v4.
  • Action: Box(-0.4, 0.4, (17,), float32); seventeen abdomen, hip, knee, shoulder, and elbow torques.
  • Observation: ordered native Box vector with 376 values.
  • Native step duration: 15.000 ms; time limit: 1,000 steps.
  • Current v5 documentation describes a different observation contract and is not used here.

Adaptation decisions

  • Native 17D continuous action head; 7D bridge is not applicable.
  • Pending no-op is the 17-dimensional all-zero vector.
  • Environment and observation clocks both use 66.66666666666667 Hz; stride = one raw frame.
  • Training latency is zero; sustained torques use hold and FIFO ordering.
  • RGB plus the complete 376D native observation is available to rollout and VLA conversion.

04 · Pipeline propagation

One contract reaches every stage

  1. GymnasiumEnvAdapter exposes the native policy observation and rendered RGB.
  2. training.gymnasium_sf trains APPO directly in the native 17D Box action space and stores the state/action contract.
  3. Teacher rollout records RGB, the exact applied continuous action, and the ordered 376D state.
  4. The generic converter writes native LeRobot actions and train-derived state normalization with robot_type=rl_games_gymnasium.
  5. QwenOFT sets action_dim=action_env_dim=17; final eval checks checkpoint, manifest, and live environment contracts before inference.
State normalization: train-derived min/max normalization maps zero-range dimensions to 0 in both conversion and online evaluation, preventing Humanoid's constant world-body fields from becoming NaN.
