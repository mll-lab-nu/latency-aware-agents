02 · Frozen contract

Raw time, policy time, and reset behavior

API FACTS

  • ALE/AirRaid-v5, ALE 0.8.1, mode 1, difficulty 0.
  • Actions: NOOP, FIRE, RIGHT, LEFT, RIGHTFIRE, LEFTFIRE.
  • PAL clock: 50 raw frames/s.
  • Native observation/render: (250,160,3) uint8.
  • Sticky actions disabled; emulator frameskip is 1.

EXPERIMENT DECISIONS

  • Zero simulated action latency.
  • One policy decision every four raw frames: 12.5 Hz.
  • Four grayscale 84×84 observations stacked along the channel axis.
  • Training reset uses noop_max=0.
  • Evaluation uses noop_max=30 and explicit FireReset.

observation_stride = 50 / 12.5 = 4 raw frames · latency_raw_frames = 0

07 · Limits

What this result does and does not establish

  • The protocol uses one ALE mode, one difficulty, no sticky actions, and seed 0 training.
  • Evaluation is capped at 5,000 raw frames, so its scores are not directly comparable to longer training episodes.
  • Random-noop and FireReset are eval-only; training uses noop_max=0.
  • The four-frame policy observation is distinct from the native RGB rendering preserved for later rollout.
  • No rollout dataset or VLA model is claimed yet.
