01 / Adaptation

Adaptation

The agent inspects native ALE frames, action meanings, raw timing and reset behavior, then builds the observation and action wrappers. Small-model control uses stacked Atari observations; VLA training uses rendered RGB and the same six-action catalog.

Raw time, policy time, and reset behavior

API FACTS

  • ALE/AirRaid-v5, ALE 0.8.1, mode 1, difficulty 0.
  • Actions: NOOP, FIRE, RIGHT, LEFT, RIGHTFIRE, LEFTFIRE.
  • PAL clock: 50 raw frames/s.
  • Native observation/render: (250,160,3) uint8.
  • Sticky actions disabled; emulator frameskip is 1.

EXPERIMENT DECISIONS

  • Zero simulated action latency.
  • One policy decision every four raw frames: 12.5 Hz.
  • The small model receives four grayscale 84×84 frames.
  • Small-model training uses noop_max=0.
  • Teacher rollout and all reported evaluation use noop_max=30 plus FireReset; VLA rows contain one current RGB image and no context images.

observation_stride = 50 / 12.5 = 4 raw frames · latency_raw_frames = 0

Data and training

  • Strict teacher gate: return greater than 2,500 under random-noop 30 plus FireReset.
  • Every accepted episode contains 3,600 raw frames and 900 decision rows.
  • Native six-dimensional categorical carrier; context_window=0 and one current 224×224 RGB image.
  • QwenOFT / Qwen3-VL-4B-Instruct, scratch action head, discrete_ce, batch 16×1, 5,000 steps.

What this result does and does not establish

  • One small-model training seed and one VLA training run are reported.
  • Evaluation is capped at the shared 3,600-raw-frame budget and uses 20 episodes per latency.
  • Small-model training uses noop_max=0; the new teacher dataset and all reported evaluation use random-noop 30 plus FireReset.
  • The small model receives a four-frame grayscale stack, while the VLA receives one current RGB image.
  • L2 performance remains substantially below L0; this experiment does not establish latency robustness.
