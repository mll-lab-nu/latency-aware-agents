02 · Action-space design

One dimension per physical actuator

Walker2D / RL

  • Native action space: Box(-1,1,(6,),float32).
  • Order: right thigh, right leg, right foot, left thigh, left leg, left foot.
  • APPO predicts six Gaussian means and six standard deviations.
  • Latency pending action is the six-dimensional zero vector.

OpenVLA

  • The action head directly regresses the same six torque dimensions.
  • Rollout rows retain the same six-dimensional order.
  • No carrier padding or gripper placeholder is added.
  • Online decoding passes all six values to Walker2D.

The final QwenOFT checkpoint uses the same high-return teacher data, native six-dimensional action head, L1 objective, batch 16, action horizon 1, 5,000-step budget, seed 42 training configuration, and a learned 17 → hidden_dim state projection. The post-fix online evaluator requests the image size saved with that model.

Closed-loop outcome

  • Return range: 365.606–1,701.006; median 892.992.
  • Episode-length range: 181–1,000 steps; mean 469.5.
  • Four of twenty trajectories reach the full 1,000-step horizon.
  • No invalid or dropped actions occur.

Teacher gap

  • Small-model L0 mean return: 3,743.507 across 10 episodes.
  • QwenVLA L0 mean return: 983.915 across 20 episodes.
  • QwenVLA reaches 26.3% of the small-model mean return.
  • The L0 rerun does not establish non-zero-latency robustness.
Interpretation: the corrected image contract reveals meaningful closed-loop control, including full-horizon episodes, but the broad return distribution and remaining teacher gap make this a partial recovery rather than solved imitation.
