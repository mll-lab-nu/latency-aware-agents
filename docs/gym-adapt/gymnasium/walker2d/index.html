OpenVLA adaptation and training details

01 / Adaptation

Adaptation

The agent derives the six-actuator order from the environment, retains the native torque vector, and implements continuous actions throughout the scheduler, teacher dataset and VLA head. It verifies the seventeen-dimensional state and saved image-size contract.

One dimension per physical actuator

Walker2D / RL

  • Native action space: Box(-1,1,(6,),float32).
  • Order: right thigh, right leg, right foot, left thigh, left leg, left foot.
  • APPO predicts six Gaussian means and six standard deviations.
  • Latency pending action is the six-dimensional zero vector.

OpenVLA

  • The action head directly regresses the same six torque dimensions.
  • Rollout rows retain the same six-dimensional order.
  • No carrier padding or gripper placeholder is added.
  • Online decoding passes all six values to Walker2D.
