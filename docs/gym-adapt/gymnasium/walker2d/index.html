02 · Action-space design

One dimension per physical actuator

Walker2D / RL

  • Native action space: Box(-1,1,(6,),float32).
  • Order: right thigh, right leg, right foot, left thigh, left leg, left foot.
  • APPO predicts six Gaussian means and six standard deviations.
  • Latency pending action is the six-dimensional zero vector.

OpenVLA

  • The action head directly regresses the same six torque dimensions.
  • Rollout rows retain the same six-dimensional order.
  • No carrier padding or gripper placeholder is added.
  • Online decoding passes all six values to Walker2D.

07 · Controlled VLA comparison

Continuous state hurts L0 but improves L2

−42.3%L0 return vs text bins
−22.7%L0 episode length
2.45×L2 return vs text bins
2.08×L2 episode length

Both QwenOFT runs use the same teacher data, native six-dimensional action head, L1 objective, batch 16, action horizon 1, 5,000-step budget, seed 42 training configuration, and seed 0 evaluation episodes. The intervention removes the 17-value 256-bin numeric string from the prompt and adds a learned 17 → hidden_dim projection to each action-query embedding.

Closed-loop outcomes

  • Text bins at L0: 164.741 ± 148.321 return, 237.0 mean steps.
  • Continuous at L0: 95.046 ± 77.904 return, 183.2 mean steps.
  • Text bins at L2: 251.058 ± 187.877 return, 146.45 mean steps.
  • Continuous at L2: 615.544 ± 298.872 return, 304.85 mean steps.

Interpretation boundary

  • No VLA episode reaches the 1,000-step horizon in either new latency condition.
  • Final held-out L1 is slightly worse with continuous state: 0.03077 versus 0.02661.
  • The L2-over-L0 reversal may reflect action-hold dynamics or sampling variance; this evaluation does not identify its mechanism.
  • A second training seed and repeated closed-loop seed blocks are required before selecting an encoding.
Offline/online mismatch: held-out L1 ranks text bins slightly better overall, but cannot predict the direction or magnitude of the L2 improvement. Neither aggregate offline loss nor one latency is sufficient for model selection.

09 · Limits and next stage

Do not select a Walker state encoding from this single reversal

  • Continuous small-model training and L0–L4 evaluation remain verified.
  • Both RGB+state QwenOFT encodings use one training seed and one 20-episode seed block per latency.
  • The continuous projector is worse at the training latency and better at L2; this interaction needs replication before architectural conclusions.
  • Neither VLA approaches the small-model L0 return or reaches a full 1,000-step episode.
  • The next discriminant experiment is a second training seed followed by matched L0/L2 evaluation; recovery-state aggregation remains the data-side follow-up.
