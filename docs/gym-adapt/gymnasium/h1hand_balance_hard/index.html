02 · Frozen contract

Native whole-body control, no discretization

Runtime facts

  • Native ID: h1hand-balance_hard-v0.
  • Benchmark ID: LatencyBench/H1HandBalanceHard-v0.
  • Action: Box(-1, 1, (61,), float32).
  • Observation: Box(..., (177,), float64).
  • MuJoCo timestep is 2 ms with frame skip 10, yielding 50 Hz.
  • Native episode limit is 1,000 steps.

Benchmark decisions

  • env_fps: 50, obs_fps: 50, one state frame.
  • Latency queues complete 61-value vectors.
  • The pending no-op is the keyframe actuator-length target, normalized into [-1, 1].
  • Actuator labels come from runtime MuJoCo order, including tendon-driven hand controls.
  • This first baseline uses zero latency and privileged state.

03 · Compatibility boundary

A family wrapper contains the two upstream mismatches

Registration

One family registry maps five benchmark task keys to their official HumanoidBench IDs and native horizons.

MuJoCo 3.3

Three removed 3.1 named-index fields are deleted before HumanoidBench constructs its indexers.

Action type

Sample Factory's 61-value Python list is converted to the declared float32 ndarray.

Native task

Observation, reward, termination, rendering and action values pass through unchanged.

The compatibility code is owned once by the HumanoidBench family. The generic Gymnasium adapter and Sample Factory integration were not modified.

05 · Reproduction

Install, probe, train and evaluate

Runtime setup
git submodule update --init third_party/sample-factory third_party/humanoid-bench
apt-get install -y libegl1
uv pip install --python .venv/bin/python -e third_party/sample-factory
uv pip install --python .venv/bin/python \
  'jax==0.4.28' 'jaxlib==0.4.28' 'numpy==1.26.4' \
  'scipy==1.15.3' 'ml-dtypes==0.5.3' 'opt-einsum==3.4.0' \
  'imageio==2.34.2'
uv pip install --python .venv/bin/python --no-deps -e third_party/humanoid-bench
Probe and tests
MUJOCO_GL=egl .venv/bin/python scripts/scaffold_humanoidbench.py \
  --task-name h1hand_balance_hard \
  --report-path artifacts/h1hand_balance_hard/api_probe.json \
  --env-yaml-path artifacts/h1hand_balance_hard/env_block.yaml

MUJOCO_GL=egl WANDB_MODE=disabled .venv/bin/python -m pytest -q \
  tests/envs/test_gymnasium_humanoidbench.py \
  tests/envs/test_gymnasium_env_adapter.py \
  tests/training/test_gymnasium_sf.py
APPO smoke and evaluation
MUJOCO_GL=egl WANDB_MODE=disabled .venv/bin/python -m training.train \
  --config configs/examples/gymnasium/h1hand_balance_hard/small_model_train.yaml

MUJOCO_GL=egl WANDB_MODE=disabled .venv/bin/python -m latency_bench.run \
  --config configs/examples/gymnasium/h1hand_balance_hard/small_model_eval.yaml

06 · Limits

Claims intentionally deferred

  • The smoke policy is not converged and does not establish a competitive HumanoidBench score.
  • No nonzero latency sweep or latency-sensitivity claim was made.
  • No VLM language head or continuous VLA action head was implemented.
  • starvla_eval.yaml records the future task contract but remains NOT RUN.
