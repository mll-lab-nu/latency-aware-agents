# Hugging Face cards

Maintained root cards for the three main LAGEN repositories:

| Repository | Card source |
|---|---|
| Models | [benchmark-models](benchmark-models.md) |
| Data and experiment manifests | [benchmark-datasets](benchmark-datasets.md) |
| Latency profiles | [profiles](profiles.md) |

The [paper experiment catalogue](https://huggingface.co/datasets/MLL-Lab/LAGEN-datasets/tree/e983a3a72e042c6fab5575b847cdf6f4432cddaa/experiments) links experiment, task, and run pages.
Root cards provide navigation.
Task pages and fixed manifests identify detailed settings and source limits.
