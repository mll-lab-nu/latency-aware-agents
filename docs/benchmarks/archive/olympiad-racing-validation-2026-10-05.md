## 用户授权的模型试赛

两模型均使用 L1 / seed101 / ×10、Codex 0.158.0、medium reasoning，禁止联网检索。
凭证只由已有 `.env` 与仿真代理读取，没有复制到代码或模型席位。模型本身生成驾驶
程序，通过相同相机／命令接口比赛；没有给模型参考选手程序。

| 模型与实际路由 | 验收结果 | 圈时间 |
| --- | --- | --- |
| gpt-6-luna / OpenRouter | 两圈、获胜；valid_trial=1、deterministic=1；83 个控制步发生车车接触；无 API／meter 错误 | 第一轮 13.7966 s，第二轮 9.8694 s |
| gpt-6-astra / Azure | 两圈、获胜；valid_trial=1、deterministic=1；9 个控制步发生车车接触；无 API／meter 错误 | 第一轮 11.4567 s，第二轮 11.4184 s |

Luna 使用黄色中心线与公开相机标定估计路线，校准车道偏移，生成自主驾驶程序，并在
两轮之间提交了有比赛依据的 WHY/PLAN。第一轮和第二轮起跑道、实际行驶距离不同，
不能把第二轮更快直接当作赛中修改的因果收益。试赛暴露了文档含糊处：完成一圈后
自动刹车，但世界仍等待另一车或限时结束；已在赛车专用规则里写明。

Luna 的仿真计量记录为 51 次完成模型请求、1,582,152 输入 tokens、17,332 输出 tokens，
0 次失败和 0 次 rate-limit retry。这里统计累计计量 tokens，不推算计费美元或缓存价。

Astra 的代理记录确认 `route=azure`、`model=gpt-6-astra`、`azure_deployment=gpt-6-astra`；
40 次完成模型请求、797,237 输入 tokens、4,322 输出 tokens，0 次失败和重试。
其驾驶程序从黄色中心线像素恢复路面投影，拟合曲线、按弯曲程度调整速度，观察完赛
和换道后继续比赛。两模型的完整集成状态、分数和接触记录均通过独立新进程验证。

本次是各一个任务实例的可解性／行为试赛，不是模型排名，也没有覆盖双模型直接对跑。
调用次数、准备时长和赛中修改效果仍需专门实验，不能用胜负代替分析。

## 版本与复验

试验开始后没有修改生成的运行任务。试赛期间在源目录补充了倒车跨起点时的进度
解缠绕、启动时固定源码指纹，以及完赛自动刹车的规则文字。前两项在单元测试中
覆盖；最终生成版本另运行了一次完整 Harbor 相机参考比赛，赢且有效、确定。

对已记录动作进行最终裁判版本兼容重放时，原记录保留不动，在临时副本中显式换为
当前源码指纹，然后重新执行物理与裁判，比较完整状态、分数和接触记录。这是版本
兼容检查，**不是新模型试赛，也不意味着最终验证器接受任意旧版本轨迹**。
原试赛各自已由对应版本的独立验证器验收。七条已完成试验的兼容重放均匹配原完整
状态、分数和接触记录；结果与来源指纹另存原始证据。
