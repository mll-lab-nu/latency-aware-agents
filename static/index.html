Human Evaluation Instructions

Use eval mode for formal data collection. Finish one environment before switching to the next.

  1. Enter the participant name.
  2. Select one environment.
  3. Set episodes per latency, max steps, and the latency range.
  4. Press Start Eval and play until the session finishes.
  5. After the finished status appears, select the next environment and start a new eval session.

Controls: Flappy uses Space, Up, or W. Demon Attack uses Left/Right plus Space. Deadly Corridor uses WASD, arrows, and Space.
