## Task
Bowl a 10-frame game of ten-pin bowling on a regulation MuJoCo lane (oiled front end, dry back end, 10 rigid pins, a 7 kg ball), each ball a release (board, launch angle, speed, rev rate, axis rotation) chosen from the camera images; format `single` (seats A),
action level `low`, program play. Generated by `tools/generate.py` from
`sports/bowling/sport.toml`; do not edit by hand.

## Difficulty
Set at run time: the seed (`RO_SEED`; it draws the match's random conditions).

## Reference solution
`solution/solve.sh` runs the sport's reference player (`solution/builtin_players.py`) through the core's client
(`solution/ro_client.py`): camera images and `/spec` only.

## Verification
The `sim` service (the v0.2 core, `environment/sim/core/`) records the match (`episode.jsonl`) and a fresh process
replays it (state hash); the verifier (`tests/grade.py` = `core/grading.py`, no network) writes the common reward
fields (`success`, `valid_trial`, `deterministic`, `<seat>_won`, ...) and the sport's fields (`tests/sport_grade.py`).

| Rules | [USBC Playing Rules 2025-2026 (Chapter 2, General Playing Rules; rev. 07/25)](https://bowl.com/getmedia/cabf49db-8cc5-4ce4-abc0-dfca1a1d7706/071724_USBC-Playing-Rules.pdf) version 2025-2026 |
| id | rule | deviation |
| D1 | 6a | a pin counts as down if it tilts more than 20 degrees or leaves the lane surface (gutter, pit, kickbacks); a pin standing anywhere on the lane counts as standing (USBC 7b) |
| D2 | 5a | no fouls: the ball is laid down 35 cm past the foul line by the release primitive |
| D3 | 6b.2 | no rear cushion rule: pins that rebound from the pit are counted like any other pin (down if off the lane surface) |
| D5 | Chapter 2 (the bowler delivers the ball) | the ball is delivered by a declared release machine, like the United States Bowling Congress's E.A.R.L. bowling robot (Enhanced Automated Robotic Launcher, USBC equipment specifications, https://bowl.com/equipment-specifications2024/e-a-r-l-the-robot), not by a bowler: you set its release and it rolls the ball with a stated execution scatter. Release speed 4.47 to 10.73 m/s = E.A.R.L.'s 10 to 24 mph (until bowling-3: 3 to 11 m/s, beyond the robot's range at both ends); rev rate 0 to 700 rpm (E.A.R.L.: 50 to 900 rpm; rates below 50 rpm, a ball with practically no revs, are kept, an allowance beyond the robot); the caps hold for the commanded release, the executed one scatters around it; the execution scatter is an estimate, not a number of E.A.R.L.'s |
