## Task
Robot baseball in real time (slowed down): a kinematic swing rig with a 0.84 m wooden bat against pitches with drag and Magnus lift, a bat-ball impulse model and fixed fielders; the score is the bases a batter collects (walk or single 1, double 2, home run 4); format batting: you bat 5 plate appearances against a scripted computer pitcher (levels 1-4, `game spec` match.opponent_level) and need at least 4 bases; format duel: two players alternate as batter and pitcher, 5 plate appearances each, more bases wins; format `batting` (seats A),
action level `low`, program play. Generated by `tools/generate.py` from
`sports/baseball/sport.toml`; do not edit by hand.

## Difficulty
Set at run time: the seed (`RO_SEED`; it draws the match's random conditions).

## Reference solution
`solution/solve.sh` runs the sport's reference player (`solution/builtin_players.py`) through the core's client
(`solution/ro_client.py`): camera images and `/spec` only.

## Verification
The `sim` service (the v0.2 core, `environment/sim/core/`) records the match (`episode.jsonl`) and a fresh process
replays it (state hash); the verifier (`tests/grade.py` = `core/grading.py`, no network) writes the common reward
fields (`success`, `valid_trial`, `deterministic`, `<seat>_won`, ...) and the sport's fields (`tests/sport_grade.py`).

| Rules | [MLB Official Baseball Rules](https://mktg.mlbstatic.com/mlb/official-information/2026-official-baseball-rules.pdf) version 2026 |
| id | rule | deviation |
| D1 | 5.05, 5.06, 7.01 | no base runners, runs or innings: each plate appearance scores the bases the batter reaches (walk or single 1, double 2, home run 4; no triples); format duel: plate appearances alternate between the players, 5 each |
| D2 | 5.05(b)(2) | the batter has no body, so there is no hit by pitch |
| D3 | 5.09(a)(1), Foul Tip | fouls are never caught and there are no foul tips |
| D4 | Fair Ball | fair or foul is judged at the first landing point, also for short balls |
| D5 | Strike Zone | the strike zone is judged in one plane (y = 0) at fixed heights (0.46-1.07 m, |x| <= 0.216 m, grown by the ball radius) |
| D6 | 2.01 | a uniform fence 100 m from home plate, 3 m high (MLB: 325 ft at the lines, 400 ft to centre); fixed fielders without errors |
| D7 | - | a plate appearance that reaches 15 pitches without ending is an out (MLB has no limit; two-strike fouls cannot stall the game) |
| D8 | 5.07(c) | format duel: the pitcher only chooses the pitch (type, speed, target at the plate; a fixed windup and release point, a seeded execution scatter); no pitch commanded by the release is an automatic ball, like a pitch-clock violation |
| D9 | 7.01(b) | format duel: level bases after the regulation plate appearances: one more each, up to 5 extra pairs (MLB plays extra innings until decided); still level, the last resort is not from the rulebook: the winner of the last pitch (the batter if it ended the plate appearance on base, else the pitcher) |
