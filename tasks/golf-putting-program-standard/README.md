## Task
Play a round of 4 mini-golf putting holes (par 2, 2, 2, 3; par 9) on sloped greens enclosed by walls, one hole with an obstacle block; each stroke is an aim and a speed chosen from the camera images, and the fewest strokes is best; format `single` (seats A),
action level `low`, program play. Generated by `tools/generate.py` from
`sports/golf/sport.toml`; do not edit by hand.

## Difficulty
Set at run time: the seed (`RO_SEED`; it draws the match's random conditions).

## Reference solution
`solution/solve.sh` runs the sport's reference player (`solution/builtin_players.py`) through the core's client
(`solution/ro_client.py`): camera images and `/spec` only.

## Verification
The `sim` service (the v0.2 core, `environment/sim/core/`) records the match (`episode.jsonl`) and a fresh process
replays it (state hash); the verifier (`tests/grade.py` = `core/grading.py`, no network) writes the common reward
fields (`success`, `valid_trial`, `deterministic`, `<seat>_won`, ...) and the sport's fields (`tests/sport_grade.py`).

## Details
| | |
|---|---|
| Rules | [WMF Rulebook 2.3, Worldwide international sport rules (World Minigolf Sport Federation); secondary: R&A/USGA Rules of Golf 2023](https://gov.minigolfsport.com/rules/2_3.pdf) version 2.3 |
| id | rule | deviation |
| D1 | 2.7, 8 | the greens are enclosed by walls: no border line and no out of bounds |
| D2 | 11.3 | no time limit per stroke: the player has a chess clock instead (clock out: the round ends there, the unfinished hole and the holes not played score 7 each) |
| D5 | none (the player plays the ball with the putter) | the ball is struck by a declared putting machine, like the swing robots of Golf Laboratories (robotic hitting machines used for independent club and ball testing; https://www.golflabs.com/robotics-information), not by a player: you set the putt's aim and the ball's initial rolling speed and the machine strikes with a stated execution scatter. Speed 0.05 to 6.0 m/s (the ball's start speed): media reports of these robots give club-head speeds from 0.1 mph (0.045 m/s) for putters to 120 mph (https://robohub.org/robot-golfer-hits-hole-in-one/, 2016), Golf Laboratories' own page today 5 to 130 mph (2.2 to 58 m/s), so the fast end is well within the machine and the slow end has only the media source (weak); the execution scatter is an estimate, not the machine's number. The 6.0 m/s cap is used in full: on the hole with the block some starts need a bank shot of about 5.9 m/s |
