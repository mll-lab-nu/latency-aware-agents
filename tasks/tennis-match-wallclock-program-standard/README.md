## Task
Robot singles tennis on a regulation court in real time (slowed down): a Franka Panda arm with a racket on an x-y rail base, the ball with drag, Magnus lift, a hard-court bounce and a racket impact law; first to 5 points; format match: you against a scripted computer opponent (levels 1-4, `game spec` match.opponent_level), format duel: two players; the players serve (ITF Rules 16-22, tie-break order); format `match` (seats A),
action level `high`, program play. Generated by `tools/generate.py` from
`sports/tennis/sport.toml`; do not edit by hand.

## Difficulty
Set at run time: the seed (`RO_SEED`; it draws the match's random conditions).

## Reference solution
`solution/solve.sh` runs the sport's reference player (`solution/builtin_players.py`) through the core's client
(`solution/ro_client.py`): camera images and `/spec` only.

## Verification
The `sim` service (the v0.2 core, `environment/sim/core/`) records the match (`episode.jsonl`) and a fresh process
replays it (state hash); the verifier (`tests/grade.py` = `core/grading.py`, no network) writes the common reward
fields (`success`, `valid_trial`, `deterministic`, `<seat>_won`, ...) and the sport's fields (`tests/sport_grade.py`).

## Details
| | |
|---|---|
| Rules | [ITF Rules of Tennis 2026 (English)](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf) version 2026 |
| id | rule | deviation |
| D1 | 5-7 | one tie-break-style game to 5 points instead of games and sets (Rule 5 b, shorter): from 4:4 a lead of 2 is needed, without a cap (the serving order is the tie-break's; since revision wallclock-8 + duel-6, 2026-10-08: the earlier cap of 7 points favoured one serving order whenever the server's point rate was far from 1/2); the match also ends after 400 racket hits or 40 points played: the player ahead wins, at equal points the winner of the last point |
| D2 | 16 | the robot has one arm and holds the racket (Rule 16: a one-armed player may release the ball with the racket): the release is a `toss` command: the ball appears at a declared point (0.3-2.4 m high, within 1.3 m horizontally of the base) and is projected straight up by a declared height (0-1.0 m), without spin; the rulebook allows a release in any direction |
| D3 | 24 i | only the strings touch the ball: it passes through the racket frame, the arm and the base |
| D4 | - | the robot moves on rails over its whole half (|bx| <= 5.9, -15.4 <= by <= -0.4; up to 4 m/s and 8 m/s^2); the stance rules are judged on the base: at the release it must be at rest (< 0.1 m/s) with its centre behind the base line between the centre mark and the singles sideline (Rule 16), and a base that moves more than 0.10 m between the release and the strike is a foot fault (Rule 18); a toss from a wrong stance is refused, not faulted |
| D5 | - | the last resort of the no-draw rule (equal points at the match limit and no point won) is not from the rulebook: the player who received first wins (format match: the opponent, since you serve first) |
| D6 | 21 | the serve window: it opens 1.0 s after the point starts (the receiver is ready) and closes 6 s later (a second serve or a let: opens at once, 4 s for a second serve); no toss within it is a service fault (undue delay), every time (the rulebook leaves the timing to the officials; no disqualification) |
| D7 | 5 b | format match: you serve the first point; duel: the first server is match.first_server (the runner plays both orders; there is no toss for service) |
